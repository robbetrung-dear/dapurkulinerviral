Cara Kerja Sinkronisasi Multi-Device & Hosting Cloudflare Pages
1. Live Socket Tanpa Perlu Server Tambahan

Firebase Realtime Database berjalan langsung dari browser pelanggan dan HP admin via WebSocket. Website statis yang di-host di Cloudflare Pages tidak memerlukan runtime server terpisah untuk menyiarkan update data.

2. Perubahan Menu & Pesanan Masuk Realtime

Saat Anda mengedit harga, menu, atau promo di Panel Admin, perubahan langsung tampil di layar pelanggan seketika tanpa perlu refresh browser. Saat pembeli memesan, notifikasi audio langsung berbunyi di kasir.

Panduan Lengkap Deployment ke Cloudflare Pages

Langkah demi langkah menyebarkan website Dapur Kuliner Viral ke Cloudflare Pages dengan CDN gratis global, SSL otomatis, dan serverless functions.

1 Push Source Code ke GitHub Repository

Jalankan perintah ini di terminal proyek Anda untuk menyimpan kode ke akun GitHub:

git init
git add .
git commit -m "feat: deploy dapur kuliner viral"
git branch -M main
git remote add origin https://github.com/USERNAME/NAMA-REPO-ANDA.git
git push -u origin main
2 Hubungkan Repository di Dashboard Cloudflare
  1. Buka Cloudflare Dashboard (dash.cloudflare.com).
  2. Pilih menu Workers & Pages di bilah navigasi kiri, lalu klik Create application → tab Pages → Connect to Git.
  3. Pilih repositori GitHub yang baru saja Anda push.
  4. Isi pengaturan Build settings persis seperti berikut:
Framework preset None / Vite
Build command npm run build
Build output directory dist
Root directory / (Kosongkan / Default)
3 Atur Environment Variables di Cloudflare Pages

Masuk ke menu Settings → Environment variables pada proyek Pages Anda di Cloudflare dan tambahkan variabel berikut:

Variable Name Value Contoh Keterangan
MIDTRANS_SERVER_KEY SB-Mid-server-xxxxxxxxxxxx Server Key dari dashboard Midtrans
MIDTRANS_CLIENT_KEY SB-Mid-client-xxxxxxxxxxxx Client Key untuk frontend Snap
MIDTRANS_IS_PRODUCTION false (atau true) false untuk Sandbox, true untuk Production
4 Serverless Functions & Custom Domain

Direktori /functions/payment.js dan /functions/ongkir.js akan otomatis dideteksi dan dieksekusi oleh Cloudflare Pages Functions di jaringan edge global tanpa biaya server tambahan. Anda juga dapat menambahkan Custom Domain Anda sendiri (seperti order.dapurkuliner.com) gratis dengan sertifikat SSL otomatis.
